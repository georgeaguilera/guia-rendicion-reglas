# Reglas de la Guía de Rendición · Fondos de Cultura

El programa *Guía de Rendición* descarga `reglas.xlsx` desde este repositorio cada vez que se abre. Con esas reglas arma la guía de documentos que cada responsable debe presentar.

Para publicar una versión nueva:

1. Sube el número de **Version** en la hoja Leeme.
2. Valida el archivo con el acceso directo "Validar reglas de rendición".
3. Súbelo aquí con el mismo nombre, `reglas.xlsx` (Add file → Upload files).

Si algo sale mal, restaura la versión anterior desde el historial. Mientras tanto, cada programa sigue usando su última copia buena.

La guía orienta, pero no reemplaza el convenio, las bases ni al supervisor del Ministerio.
